Building SQL queries by concatenating or interpolating untrusted data lets an attacker alter the query and read, modify or delete arbitrary data (SQL injection).

Noncompliant Code Example

db.rawQuery('SELECT * FROM users WHERE id = $userId');

Compliant Solution

db.rawQuery('SELECT * FROM users WHERE id = ?', [userId]);

  • CWE-89 - Improper Neutralization of Special Elements used in an SQL Command
