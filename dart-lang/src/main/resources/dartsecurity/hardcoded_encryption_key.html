Cryptographic keys and initialization vectors that are hardcoded in the source code can be extracted from the application binary, defeating the encryption entirely. A well-known example is an app that shipped with the key "PRODKEYPRODKEY12" embedded in its code.

Ask Yourself Whether

  • The key or IV protects sensitive data.

Recommended Secure Coding Practices

  • Derive keys at runtime from a secret that is not stored in the source code.
  • Store secrets in a secure storage (Keychain / Keystore) and use a unique, random IV per operation.
