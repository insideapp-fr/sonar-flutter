Enabling unrestricted JavaScript in a WebView widens the attack surface: malicious or compromised remote content can run scripts, and any exposed JavaScript channel can be abused to reach native code.

Ask Yourself Whether

  • The WebView can load content you do not fully control.

Recommended Secure Coding Practices

  • Only enable JavaScript when required, and only load trusted content over HTTPS.
  • Restrict or carefully validate any JavaScript channels exposed to the page.
