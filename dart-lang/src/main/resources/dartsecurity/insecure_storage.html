Mobile shared preferences (SharedPreferences / NSUserDefaults) store data in clear text on the device. Sensitive data such as tokens, passwords or personal information stored there can be read by anyone with access to the device or a backup.

Ask Yourself Whether

  • The stored value is a credential, token, or personal data.

Recommended Secure Coding Practices

  • Use flutter_secure_storage, which relies on the iOS Keychain and Android EncryptedSharedPreferences/Keystore.
  • Whenever possible, avoid persisting sensitive data on the device at all.
