Because it is easy to extract strings from an application source code or binary, credentials should not be hardcoded. This is particularly true for applications that are distributed, such as mobile apps.

Ask Yourself Whether

  • Credentials allow access to a sensitive component like a database, a file storage, an API or a service.
  • Credentials are used in production environments.

Recommended Secure Coding Practices

  • Store credentials outside of the code, in a configuration file, an environment variable or a secret manager.
