Building an operating-system command from untrusted data lets an attacker execute arbitrary commands on the device (command injection).

Noncompliant Code Example

Process.run('sh', ['-c', 'ls $path']);

Compliant Solution

Process.run('ls', [path]); // arguments passed as a list, not interpolated into a shell string

See

  • CWE-78 - Improper Neutralization of Special Elements used in an OS Command
